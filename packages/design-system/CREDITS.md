- `fonts/UthmanTN_v2-0.ttf` is the original, digitally signed file (SHA-256 `f4a2b776261e390089ee108029d9a5f1ee862435ea52f571af2c5e0817c361ba`). `fonts/UthmanTN_v2-0.woff2` repackages it losslessly: glyphs, hinting and metrics are identical, and only the signature is absent because WOFF2 cannot carry it. The font is never subset or edited.
